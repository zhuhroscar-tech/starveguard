# Changelog

All notable changes to `starveguard` are documented here.

## v0.1.2 — 2026-09-24

- Added release-history documentation and repository contract tests.
- Added sdist manifest coverage for changelog, workflow, tests, and bilingual README files.
- Kept package/runtime version metadata in sync with the maintenance release.

## v0.1.1 — 2026-09-24

- Modernized Python packaging license metadata to the current SPDX form.
- Added regression tests for license-file packaging metadata.
- Verified local tests, build, CLI smoke checks, GitHub Actions CI, CodeQL, and release artifacts.

## v0.1.0 — 2026-09-15

- Initial public release of the deterministic priority-queue starvation simulator.
- Added CLI reports for balanced, heavy-contention, and light-contention scenarios.
- Included Python APIs for custom comparator simulations.
